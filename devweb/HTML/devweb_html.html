HTML5: A Estrutura da Web

O HTML (HyperText Markup Language) é a linguagem de marcação padrão responsável por estruturar e dar significado ao conteúdo de uma página web.

Através de elementos delimitados por tags (como <h1> , <p> e <article> ), o HTML organiza títulos, parágrafos, imagens, links e formulários, formando a espinha dorsal de qualquer site.
